# Adding screenshots

Screenshots make the README far more useful. To add them **without exposing a real camera
feed**:

- **Point the camera at a neutral scene** (a blank wall, a plant) or cover the lens before
  capturing the live view. Never show anything identifying — faces, licence plates, your
  home interior, address, etc.
- **Do not screenshot the Settings window.** It contains the Device ID and password
  fields. If you must show setup, blur or crop those out completely.
- Everything else is safe: the main UI shows no credentials. Good shots are the **live
  view** (neutral scene), the **recordings timeline**, the **PTZ pad**, and **zoom**.
- Save PNGs in this folder as `live.png`, `recordings.png`, `ptz.png`, then reference them
  from the README's Screenshots section.

## Capturing on macOS

- One window: press **⇧⌘4**, then **Space**, then click the window.
- A region: **⇧⌘4** and drag.
- The screenshot toolbar: **⇧⌘5**.

Prefer trimming to just the app window, and double-check the image before committing —
once it is pushed to a public repo, it is public.
